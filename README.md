# DSCI552-Homework4

This repository contains my Homework 4 Jupyter notebook. It analyzes
the AReM activity data using logistic regression and Naive Bayes, and
includes solutions to ISLR Exercises 4.8.3 and 4.8.7.

## Files

- `Homework 4.ipynb` — analysis, figures, results, and written answers
- `AReM/` — activity data used by the notebook

## Running the notebook

Place the `AReM` folder in the same directory as `Homework 4.ipynb`.
The notebook expects the relative path `AReM/`.

Install the required packages:

```bash
pip install numpy pandas scipy matplotlib scikit-learn jupyter
